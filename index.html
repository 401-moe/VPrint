VPrint 是 XCPC 训练用的电子打印机。主机发出代码，队友就能在自己的屏幕上按行号一起看。

进入训练工作区 → 试读打印件 ↓

int gcd(int a, int b) {
    while (b) {
        int r = a % b;
        a = b;
        b = r;
    }
    return a;
}

开始一场训练

先在工作区创建或加入队伍，建好比赛。接下来，只需在训练目录里操作。

下载命令行工具 →

授权主机，选定比赛

打开终端给出的网址确认短码，再选这次训练的队伍和比赛。

$ vprint login

请在浏览器打开 https://vprint.ac/device
等待浏览器授权…
已登录 team@example.org

$ vprint use

已绑定 校队 / 周六训练

打印当前文件

核对比赛和文件名，按回车发送。队友能在比赛列表看到新打印件。

$ vprint A.cpp

当前比赛　校队 / 周六训练
文件名　　A.cpp
文件大小　115 字节

确认打印？ [Y/n]
