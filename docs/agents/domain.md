# 领域文档

VPrint 的 Web、CLI 和服务端共用一份[领域术语表](../../GLOSSARY.md)。开始设计或拆单前先核对术语。工单、界面、测试中的「队伍」「队长」「比赛」「打印件」「已登录会话」均沿用其中的定义。

产品流程见[产品设计](../../DESIGN.md)，可观察的行为与验收场景见[产品规格](../../SPEC.md)。引用验收场景时沿用已有的 S 编号。

架构决策记录集中在根目录下的 `docs/adr/`。涉及已有决策时先阅读对应记录；发现冲突时注明涉及的决策和需要重新讨论的原因。首次形成需要记录的架构决策时再创建该目录。出现新的领域概念时，与队员或维护者确认含义后更新术语表。
