# ADR 0001: Paper 桌面纸感视觉与四层独立页面工作区

- 状态：已采纳（2026-11-26）
- 决策来源：`/proto/workspace` 实机对比探索（Paper / Linear / Night）

## 决定

采用 **Paper** 方向并配合严格**四层独立页面**架构重写 VPrint Web 前端（`src/web/*`、`workspace.html`）：

1. **视觉与排版令牌**
   - 画布基底 `#f6f6f4`（暖石纸面），承载卡片与阅读区 `#ffffff`，边框 `#e2e1dd`、`1px` 实体边界、圆角 `6px`。
   - 正文字体 `Geist`，等宽代码字体 `Geist Mono`，数值采用 `tabular-nums`（`.vp-num`）。
   - CSS 变量定义在 `:root` 作用域，确保 `@base-ui/react` Portal 弹窗（`Dialog`、`Menu`）在 `document.body` 下拥有 100% 不透明表面、正确主题色与遮罩层；弹窗进入 `160ms` / 退出 `110ms`、`cubic-bezier(0.23, 1, 0.32, 1)` 仅作用于 `opacity` 与 `transform`。
   - 所有业务命名输入（队伍名称、比赛名称、终端短码）显式关闭密码管理器与浏览器的自动填充干扰；认证表单（登录、注册、修改/重置密码）保持标准凭据语义以便密码管理器配合。

2. **四层独立页面与明确导航入口**
   - **L1 用户层级（`/workspace`、`/teams`）**：`我的队伍` 列表 + 右上角 `账号设置`（`/account`）与 `+ 新建队伍`。
   - **L2 队伍层级（`/team/:teamId`）**：`比赛列表`，右上角并列 `队伍设置`（`/team/:teamId/settings`）与 `+ 新建比赛`。
   - **L3 比赛层级（`/contest/:contestId`）**：`打印列表`，右上角 `比赛设置`（`/contest/:contestId/settings`）。
   - **L4 打印件层级（`/contest/:contestId/print/:printId`）**：仅保留 `← 返回打印列表`、文件名、基础元数据与全宽只读高亮源码视图（遵守 `SPEC.md` S23，不额外添加复制/下载按钮）。

## 否决的备选方案

- **多栏混合工作台（原布局）**：在一页内同时堆叠队伍、比赛、预览、侧边栏会分散赛中读码注意力。
- **Linear 变体**：纯白无框表格加内联表单缺少页面边界，高密度列表下层次不如 Paper 清晰，故仅借鉴其头部双按钮与克制的横向分隔；在生产环境中对「新建队伍 / 新建比赛 / 危险确认」统一采用不透明 Paper `Dialog`。
- **Night 变体**：深色背景在强光赛场与白底投影下反差较高，不符合实体打印纸的心智模型；暂不纳入首版，待后续如有深色模式需求再基于同套 `:root` 令牌扩展。
